# Argus Album

Photos: every picture the pillars use, in one place.

Live: https://jpavia10.github.io/prometheus-hub/pillars/argus/ (version 1, 2026-11-05). Built on the shared kit `../../kit/` (the Prometheus look, the field, on-device storage).

**What it does now:** Every photo in one album: Titan's coin photos live from the Titan app; photos added on the phone are redrawn (no EXIF/GPS) and kept in IndexedDB, tagged by pillar.

Everything entered stays in that browser (export/import as JSON at the bottom of the page). Nothing is sent anywhere.
