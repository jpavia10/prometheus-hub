# Icarus Stake

High-risk trading journal. It never trades.

Live: https://jpavia10.github.io/prometheus-hub/pillars/icarus/ (version 1, 2026-11-05). Built on the shared kit `../../kit/` (the Prometheus look, the field, on-device storage).

**What it does now:** A trading journal: bankroll, rules, every trade, net result, win rate, expectancy, profit factor, drawdown, and what breaking the rules cost. It never trades.

Everything entered stays in that browser (export/import as JSON at the bottom of the page). Nothing is sent anywhere.
