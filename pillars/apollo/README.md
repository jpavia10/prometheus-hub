# Apollo Temple

Health, fitness, nutrition.

Live: https://jpavia10.github.io/prometheus-hub/pillars/apollo/ (version 1, 2026-11-05). Built on the shared kit `../../kit/` (the Prometheus look, the field, on-device storage).

**What it does now:** One line a day (weight, sleep, steps, training, protein, calories, water, mood), goals, a streak and 30-day trends.

Everything entered stays in that browser (export/import as JSON at the bottom of the page). Nothing is sent anywhere.
