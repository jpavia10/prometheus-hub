# Garage showroom models

No free 3D model of a 2025 Kia Sorento Hybrid or a 2021 Yamaha MT-07 was reachable, so each bay shows a stand-in
(owner, 2026-11-20: "Get a free model of a misc motorcycle and sub if u can't find mine"). The caption under the
viewer says which model is shown.

| Bay | Shown as | Author | License | Source |
|---|---|---|---|---|
| 2025 Kia Sorento Hybrid | 2015 Hyundai Tucson | razor24 | CC BY 4.0 | https://sketchfab.com/3d-models/2015-hyundai-tucson-7674a3bd168a451daf73fc0a33d39589 |
| 2021 Yamaha MT-07 | Kawasaki Z1000 (2014) | e-restrepo1114 | CC BY 4.0 | https://sketchfab.com/3d-models/z1000-2014-70cecfa5568347428c5ad72e9a156be9 |

Changes made (CC BY asks for them to be stated): compressed with glTF-Transform 4.1 (meshopt geometry, WebP textures
at 1024 px; 1.15 MB -> 229 KB and 10.2 MB -> 0.9 MB); scaled at load time to the real vehicle's length; the Tucson's
body paint set to an approximation of Kia Mineral Blue; the Z1000's copper trim toned to dark grey for a matte black
look. The authors' credit and license stay in each file's glTF asset block.

The files came from public GitHub repositories that ship the authors' original Sketchfab exports with their license
metadata intact (checked in each file before use).
